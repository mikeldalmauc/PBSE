# Chuleta · Guía básica de Markdown

> **Nota.** Esta página acompaña a la [explicación del tema](1-explicacion.md). Tenla a mano mientras trabajas.

## Resumen rápido

| Quiero… | Escribo |
|---|---|
| Título del documento | `# Título` |
| Apartado / subapartado | `## Apartado` · `### Subapartado` |
| Párrafo nuevo | Una línea en blanco |
| Negrita / cursiva | `**negrita**` · `*cursiva*` |
| Comando o ruta dentro de una frase | `` `ls -l /home` `` |
| Lista sin orden / numerada | `- elemento` · `1. paso` |
| Casilla de tarea | `- [ ] pendiente` · `- [x] hecho` |
| Enlace | `[texto](https://...)` |
| Enlace a un apartado | `[texto](#nombre-del-apartado)` |
| Imagen | `![descripción](images/fichero.png)` |
| Bloque de código | Tres acentos graves + lenguaje, código, tres acentos graves |
| Aviso | `> **Aviso.** texto` |
| Tabla | Cabecera, fila de guiones `---` y filas separadas por barras verticales |
| Línea horizontal | `---` con una línea en blanco encima |
| Salto de página al imprimir | `<div style="page-break-after: always;"></div>` |
| Índice | `Ctrl+Shift+P` → *Create Table of Contents* |
| Exportar | Clic derecho → *Print current document to HTML* → navegador → `Ctrl+P` → *Guardar como PDF* |
